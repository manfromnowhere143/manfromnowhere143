## Selected work

<img src="assets/logos/nisayon.svg" width="24" height="24" align="center" alt=""> **Nisayon** · [Repository](https://github.com/manfromnowhere143/nisayon) · [Interface](https://nisayon.danielwahnich.dev)<br>
Experiments for diagnosing robot-policy integration failures and testing corrections on fresh conditions. The [Python SDK](https://github.com/manfromnowhere143/nisayon/blob/main/docs/QUICKSTART.md) retains replayable evidence; savings in total engineering work remain unproven.

Contributed shared-weight and processor fixes to [LeRobot’s Long-WAM integration](https://github.com/huggingface/lerobot/pull/5008).

**Atlas** · Private development<br>
An agent execution and evidence system studying when to execute, verify, repair or stop. Comparative benefit remains unproven.

<img src="assets/logos/telos.svg" width="24" height="24" align="center" alt=""> **Telos** · [Repository](https://github.com/manfromnowhere143/telos) · [Interface](https://telos.danielwahnich.dev)<br>
Research on coding-agent patches that pass graded tests but fail additional checks. Findings remain limited to the tasks and reference implementations studied.

<img src="assets/logos/sentinel.svg" width="24" height="24" align="center" alt=""> **Sentinel** · [Repository](https://github.com/manfromnowhere143/sentinel) · [Interface](https://sentinel.danielwahnich.dev)<br>
Runtime monitoring and recovery around frozen driving planners. Closed-loop studies report benchmark gains, intervention costs and null transfer.

<img src="assets/logos/reiyah.svg" width="24" height="24" align="center" alt=""> **Reiyah** · [Repository](https://github.com/manfromnowhere143/reiyah) · [Interface](https://reiyah.danielwahnich.dev)<br>
An offline engine for comparing perception systems under incomplete or disputed reference evidence. Returns checked loss bounds; reduced total effort remains unproven.

<img src="assets/logos/inbar.svg" width="24" height="24" align="center" alt=""> **Inbar** · [Repository](https://github.com/manfromnowhere143/inbar) · [Interface](https://inbar.danielwahnich.dev)<br>
Research on diagnosing physical causes through tests that distinguish competing explanations. No physical result has been established.

<img src="assets/logos/odeya.svg" width="24" height="24" align="center" alt=""> **Odeya** · [Repository](https://github.com/manfromnowhere143/odeya) · [Interface](https://odeya.danielwahnich.dev)<br>
Architecture for a research engine linking questions, evidence and separately assigned verification. Contracts and fixtures exist; the engine is not built.

<img src="assets/logos/aweb.svg" width="24" height="24" align="center" alt=""> **Aweb** · Earlier work · [Website](https://aweblabs.ai)<br>
